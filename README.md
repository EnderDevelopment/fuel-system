# Fuel System

A comprehensive fuel system for FiveM servers with fuel consumption and refueling.

## Features

- Realistic fuel consumption based on vehicle movement
- Refueling functionality with configurable rates
- Database integration to save and retrieve fuel levels

## Requirements

- FiveM server
- ESX Legacy framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Run the database.sql file to create the necessary table
4. Add `start fuel_system` to your server.cfg file

## Usage

The fuel system will automatically handle fuel consumption and refueling. Players can refuel their vehicles by using the `/refuel` command.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the fuel price, consumption rate, and refuel rate to suit your server's needs.
